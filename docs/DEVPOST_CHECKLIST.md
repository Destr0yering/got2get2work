- [ ] Public YouTube URL.

## Judging alignment

- [ ] **Technological Implementation:** show strict GPT output, deterministic match facts, mutual-consent state machine, tests, and a runnable repository.
- [ ] **Design:** show the coherent Today -> Schedule -> Match -> Accept -> Recovery experience.
- [ ] **Potential Impact:** connect ride-hail commute costs and missed-shift risk to a specific worker audience.
- [ ] **Quality of the Idea:** explain the schedule-aware, cross-street-private, agentic-recovery difference from existing carpool marketplaces.
