# Galaxy Store free beta release

## Release position

- Product: Got2Get2Work, a people-first commute coordination app.
- Track: free closed beta; no subscription, fare, or in-app purchase.
- Permanent Android application ID: `com.got2get2work.app`.
- Version: `0.1.0`; Android version code: `1`.
- HoleFilled/ShiftSecure is not included in this app, listing, or data model.

## Binary gate

- [ ] Run the complete repository verification command.
- [ ] Build a signed Android App Bundle (`.aab`) using the permanent application ID.
- [ ] Install the corresponding release build on a physical Samsung device.
- [ ] Verify sign-in, account state persistence, consent capture, schedule review, match explanation, request/accept, cancellation recovery, safety report, block, export, and deletion.
- [ ] Confirm `/api/health` reports `geminiProvider: vertex-ai` and persistence configured.
- [ ] Retain the signing key and credentials in the organization-owned secure account; never commit them.

## Listing assets

- [ ] App name and short/long descriptions emphasize commute coordination—not guaranteed transportation.
- [ ] High-resolution icon and required Samsung screenshots.
- [ ] Support URL/email, privacy-policy URL, and terms URL use Got2Get2Work-owned accounts.
- [ ] Data Safety answers match actual collection, retention, deletion, location, notification, and AI processing behavior.
- [ ] Content rating and supported countries/devices selected.
- [ ] Closed-beta tester instructions and feedback channel prepared.

## Beta launch gate

- [ ] Recruit 10–25 testers from one commute community or workplace area.
- [ ] Give every tester the same task script and record funnel completion.
- [ ] Track activation: profile saved, schedule confirmed, eligible match viewed, request sent, mutual acceptance, completed/recovered commute.
- [ ] Review safety reports and failed workflows daily during the first week.
- [ ] Expand only after account deletion, privacy controls, and recovery flows work on production data.

## XPRIZE evidence generated by the beta

- Production Vertex AI execution logs with provider, model, decision ID, grounded fact IDs, and fallback events.
- Real-user activation and completed-flow counts without exposing personal commute details.
- Consent, human approval, safety, and recovery evidence.
- Testimonials or quotes only with explicit permission.
